# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the Security tab of this repository and select "Report a vulnerability". Do not open a public issue.

Include the affected component and version, the steps to reproduce and the impact.

## Scope

The code, tools and scripts in this repository. Report vulnerabilities in the vendor firmware to Raspberry Pi Ltd: <https://www.raspberrypi.com/contact/security/>.

## Supported versions

Fixes go to `dev` and to the latest release.
